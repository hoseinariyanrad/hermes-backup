# 🎬 زیرنویس‌های ترجمه شده

ترجمه زیرنویس‌های انگلیسی به فارسی روان و سینمایی

## دسته‌بندی‌ها

| دسته | توضیح |
|------|-------|
| `anime/` | انیمه و دونگهوا (انیمیشن‌های چینی/ژاپنی) |
| `series/` | سریال‌های تلویزیونی |
| `movies/` | فیلم‌های سینمایی |

## فرمت فایل‌ها

- فرمت: SRT (Standard Subtitle)
- رمزگذاری: UTF-8
- زبان: فارسی (Farsi)

## ساختار پوشه‌ها

```
subtitles/
├── anime/
│   └── jade-dynasty/
│       └── season-4/
│           ├── JD.S4.E01.FA.srt
│           ├── JD.S4.E02.FA.srt
│           └── JD.S4.E03.FA.srt
├── series/
└── movies/
```

## نام‌گذاری فایل‌ها

`[نام اثر].[فصل].[قسمت].[زبان].srt`

مثال: `JD.S4.E01.FA.srt`
- JD = Jade Dynasty (جید دایستی)
- S4 = Season 4 (فصل ۴)
- E01 = Episode 01 (قسمت اول)
- FA = Farsi/Persian (فارسی)
